# Holy Flow — Daily QT & Devotional Life App (1차 구현)

## 제품 비전
매일의 QT, 말씀 묵상, 기도제목, 감사, 영적 습관(루틴)까지 한 곳에서 기록하고 돌아볼 수 있는 **모바일/PC 반응형 웹 앱**입니다.

## 1차 기획 요약

### 핵심 사용자
- 매일 경건 시간을 꾸준히 지키고 싶은 성도
- QT/묵상/기도 노트를 디지털로 관리하고 싶은 사용자
- 주간/월간 회고를 통해 영적 성장을 추적하고 싶은 사용자

### 핵심 문제
- 기록이 여러 매체(종이/메모앱/채팅)에 흩어져 있음
- 경건 루틴의 연속성(스트릭) 확인이 어려움
- 하루의 묵상과 기도 응답을 연결해 보기 어려움

### 핵심 가치 제안
- **하루 경건 루틴을 한 화면에서** 기록
- **말씀-묵상-기도-감사**를 자연스럽게 연결
- 누적 기록과 간단 통계로 습관 형성 지원

## 주요 기능 (MVP)
1. **오늘의 QT 작성**
   - 본문/제목/묵상/적용/기도
2. **기도 제목 관리**
   - 카테고리(개인/가정/교회/일터/선교), 응답 여부 체크
3. **감사 노트**
   - 하루 3가지 감사 기록
4. **영적 루틴 체크리스트**
   - 말씀읽기/기도/암송/예배/섬김 체크
5. **대시보드 요약**
   - 오늘 작성 여부, 누적 QT 수, 기도 응답 수, 루틴 완료율
6. **로컬 저장(LocalStorage)**
   - 로그인 없이 브라우저 단위 데이터 보존

## 정보 구조 (IA)
- 대시보드
- QT 일기장
- 기도제목
- 감사노트
- 루틴 트래커

## 향후 로드맵
- 계정/클라우드 동기화 (Firebase/Supabase)
- 교회 소그룹 공유(선택 공개)
- 캘린더 기반 히스토리 & 검색/태그
- 푸시 알림(경건 시간 리마인드)
- 다크모드/접근성 강화

## 기술 스택 (1차)
- HTML5
- CSS3 (Glassmorphism + Gradient, 반응형)
- Vanilla JavaScript (모듈 패턴 + LocalStorage)

## 실행 방법
```bash
python3 -m http.server 4173
```
브라우저에서 `http://localhost:4173` 접속
